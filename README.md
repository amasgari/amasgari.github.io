# Personal homepage of Amir Abbas Asgari

This repository contains the source for my academic homepage, built with Jekyll and the Academic Pages theme. It includes my bio, research interests, publications, talks, teaching, and CV.

## Local preview

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

Then open http://localhost:4000 in a browser.

The site is published at https://amasgari.github.io.
